# Getting help

FoxieOS has no releases yet, so there is nothing to support in use.
The projects are in their planning and research phases.

- **Chat and quick questions:** the [Alopex Discord](https://discord.gg/REPLACE_WITH_INVITE), the student organization's server.
  It is for conversation, not the record: anything that should be kept, such as a bug, a correction or an argument for a decision, goes in an issue or a pull request.
- **Questions about the plan or the research:** open an issue in the repository concerned, [foxieos](https://github.com/alopex-org/foxieos/issues) or [foxieos-hardware](https://github.com/alopex-org/foxieos-hardware/issues).
- **A wrong or outdated claim in the docs:** open an issue with the source that corrects it, or a pull request.
- **A security problem:** follow the repository's `SECURITY.md`, never a public issue or Discord.
- **A code-of-conduct problem:** follow the [code of conduct](CODE_OF_CONDUCT.md#reporting-an-issue), including for something that happened on Discord.

FoxieOS is not affiliated with the LineageOS project.
Don't ask LineageOS for help with FoxieOS.
