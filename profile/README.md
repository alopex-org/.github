# FoxieOS and Alopex

The Alopex student organization is working toward a cyber-deck: a user-serviceable, portable computer with LoRa and Wi-Fi, pocket-sized if possible.
Alopex, the hardware project, works on the device; FoxieOS, the operating-system project, on its software, built on a Linux distribution for now.
Its main board, its other parts and which distribution it runs are undecided.

**Status: planning.**
Nothing is built or released yet.
The projects started out as a version of Android for phones and the hardware for it.
At their founding meeting on 2026-11-24, the members confirmed the move to a cyber-deck running a Linux distribution, and chose the projects' maintainer ([governance](https://github.com/alopex-org/.github/blob/main/GOVERNANCE.md#the-founding-meeting)).

Start with a repository's README, then its `docs/ROADMAP.md`.
Unfamiliar words are explained in the [glossary](https://github.com/alopex-org/.github/blob/main/GLOSSARY.md).

Members talk the work over on the Alopex Discord, which has no public invite for now.
Anything that should be kept goes in an issue or a pull request.
Changes follow each repository's `CONTRIBUTING.md`, the [code of conduct](https://github.com/alopex-org/.github/blob/main/CODE_OF_CONDUCT.md) and the [governance](https://github.com/alopex-org/.github/blob/main/GOVERNANCE.md).
