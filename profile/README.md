# FoxieOS

FoxieOS is a planned operating system for phones, based on Android.
The current proposal is to build it on LineageOS, an existing free version of Android, and add FoxieOS's own look, privacy settings and update service, for a short list of phones.

**Status: planning.**
Nothing is built or released yet.
The members choose the projects' maintainers at a founding meeting on 2026-11-24.
The maintainers then decide the projects' foundations together, including what FoxieOS is built on ([governance](https://github.com/alopex-org/.github/blob/main/GOVERNANCE.md#founding-maintainers)).

| Repository | What it is |
|---|---|
| [foxieos](https://github.com/alopex-org/foxieos) | The operating system: its plan, and later the scripts that build, test and release it |
| [foxieos-hardware](https://github.com/alopex-org/foxieos-hardware) | Research into building a device, separate from the operating system |
