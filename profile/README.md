# FoxieOS

FoxieOS is a planned operating system based on Android: a soft fork of LineageOS, with its own branding, privacy defaults and update server, for a short list of phones.

**Status: planning.**
Nothing is built or released yet.

| Repository | What it is |
|---|---|
| [foxieos](https://github.com/alopex-org/foxieos) | The operating system: its plan, and later its build, test and release scripts |
| [foxieos-hardware](https://github.com/alopex-org/foxieos-hardware) | Research into a prototype device for enthusiasts, separate from the operating system |

Start with a repository's README and its `docs/ROADMAP.md`.
Contributions follow each repository's `CONTRIBUTING.md`, the [code of conduct](https://github.com/alopex-org/.github/blob/main/CODE_OF_CONDUCT.md) and the [governance](https://github.com/alopex-org/.github/blob/main/GOVERNANCE.md).
